# Slovník

Pevné české termíny pro UI i překlad SRD. Jeden termín, jeden překlad, všude.
UI je bere z `client/src/lib/cs.ts`; překladový skript z tohoto souboru.

**Stav: návrh.** Termíny zatím nejsou ověřené proti Jeskyně a draci (Mytago), české lokalizaci
kompatibilní s D&D. Jakmile bude kniha po ruce, sjednotit s ní. Sloupec *Pozn.* značí, kde je
volba sporná.

## Typy zranění

Acid kyselinové, Bludgeoning drtivé, Cold chladné, Fire ohnivé, Force silové, Lightning
bleskové, Necrotic nekrotické, Piercing bodné, Poison jedové, Psychic psychické, Radiant
zářivé, Slashing sečné, Thunder hromové.

## Povolání

Barbarian barbar, Bard bard, Cleric klerik, Druid druid, Fighter bojovník, Monk mnich,
Paladin paladin, Ranger hraničář, Rogue tulák, Sorcerer čaroděj, Warlock černokněžník,
Wizard kouzelník.

## Druhy

Dragonborn drakorozený, Dwarf trpaslík (Hill Dwarf kopcový trpaslík), Elf elf (High Elf
vznešený elf), Gnome gnóm, Goliath goliáš, Halfling půlčík, Human člověk, Orc ork,
Tiefling tiefling, Half-Elf půlelf, Half-Orc půlork.

## Mistrovství zbraní

Cleave rozetnutí, Graze škrábnutí, Nick rychlý zásah, Push odhození, Sap oslabení,
Slow zpomalení, Topple povalení, Vex rozhození.

## Vlastní jména

Jména kouzel a předmětů se překládají (Magic Missile → magická střela), v závorce zůstane
anglický originál pro hledání: „Magická střela (Magic Missile)“. Jména postav, míst a bohů
se nepřekládají.
